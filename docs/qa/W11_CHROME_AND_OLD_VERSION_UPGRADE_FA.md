یک Windows Runner موقت، ابتدا نصب‌کنندهٔ قدیمی را **از کامیت واقعی** `2fb7531c2564034a861042514844b689273917f6` (شاخهٔ `release/2.7.0`) می‌سازد و نصب می‌کند؛ سپس نصب‌کنندهٔ جدید را از HEAD همان PR می‌سازد و **روی همان محل نصب** اجرا می‌کند. بررسی‌ها:

- نسخه/مانیفست واقعی نصب‌شده قبل و بعد، هش‌های فایل‌های تحت مالکیت نصب‌کننده، و تغییر باینری Runtime
- عدم تعویض Token (مقدار توکن هرگز چاپ یا آپلود نمی‌شود)
- حفظ ArtifactRoot سفارشی و تنظیم غیرحساس آزمایشی در config
- حفظ فایل کاربر خارج از InstallRoot قبل و بعد از ارتقا و حذف برنامه
- رجیستری Chrome Native Messaging و فایل Host بعد از ارتقا

این گیت فقط **ارتقای Inno روی نسخه واقعاً نصب‌شده** را بررسی می‌کند و تأیید مستقل مسیر بستهٔ Delta مربوط به Maintenance نیست.

## گیت سوم: آزمون Chrome معمولی توسط اپراتور — هنوز NOT_RUN

فقط روی یک Windows 11 آزمایشی مجزا، نه کامپیوتر خانه یا کافه و نه مرورگر/حساب واقعیِ کاری. نصب‌کننده باید از Commit دقیقِ تأییدشده با SHA256 قابل پیگیری باشد. اگر بستهٔ قابل‌راستی‌آزمایی در دسترس نیست، آزمون را BLOCKED ثبت کنید؛ از سورس غیرقابل‌تشخیص یا افزونهٔ دیگری استفاده نکنید.

1. با Chrome معمولی به `chrome://extensions` بروید؛ **Developer mode** و سپس **Load unpacked**، پوشهٔ `extension` استخراج‌شده از همان نصب را انتخاب کنید. شناسه و نسخهٔ افزونه را با manifest و Host `allowed_origins` تطبیق دهید.
2. مجوزهای افزونه را مشاهده کنید. `nativeMessaging` باید وجود داشته باشد و مجوز اختیاری دامنه‌های دیگر نباید بدون رضایت فعال شود.
3. `chrome-extension://<ID>/selftest.html` را برای بررسی داخلی افزونه باز کنید. اگر مرحله‌ای SKIP است، آن مرحله PASS محسوب نشود. از حساب ChatGPT یا سایت واقعی فقط با رضایت و محیط آزمایشی استفاده کنید.
4. `host.ping` و پاسخ `host.pong` را با شناسهٔ پیام تطبیق دهید؛ پیام ناشناخته/غیرمجاز نباید به اجرای موفق تبدیل شود.
5. با **توقف Host آزمایشی** یا حذف موقت ثبت Native Host در همان VM، شکست ایمن ارتباط را مشاهده کنید؛ سپس ثبت Host را بازگردانید و اتصال مجدد و رفتار پس از راه‌اندازی مجدد Chrome را بررسی کنید. به رجیستری دستگاه کاری دست نزنید.
6. از UI افزونه، صفحهٔ `chrome://extensions` و شواهد غیرحساسِ نتیجه عکس تهیه کنید. توکن، مسیر خصوصی، دادهٔ حساب، متن چت و credential نباید در شواهد ذخیره یا منتشر شوند.
7. هر سناریو را جداگانه `PASS`، `FAIL` یا `BLOCKED` ثبت کنید؛ بدون اجرای واقعی، `NOT_RUN`. تصویر صرفاً حضور افزونه را ثابت می‌کند، نه ارسال موفق فرمان.

تا ثبت مستندات اجرای اپراتوری، وضعیت **Chrome معمولی = NOT_RUN** باقی می‌ماند. Edge خارج از محدودهٔ آزمون و انتشار است.

## گیت‌های جدا و باز

W11 (۷۵ سناریو)، بررسی کامل حریم خصوصی، نصب روی Windows واقعی اپراتوری، بازیابی پس از Crash/قطع برق، ارتقای Delta مستقل از نصب‌کننده، امضای باینری و تأیید صریح مالک، بدون شواهد واقعی PASS محسوب نمی‌شوند.
