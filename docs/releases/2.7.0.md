# SOKNA Bridge 2.7.0

SOKNA Bridge 2.7.0 turns the Windows package from a background-only technical runtime into a user-operable product surface and adds the first Instagram Research Assistant workflow.

## User experience
- Adds **SOKNA Bridge Control Center**, a real WinForms application with no console window.
- Shows Agent health, installed version, local port, ArtifactRoot and Workspace count.
- Adds Start / Stop / Restart, logs, ArtifactRoot and Support Bundle controls.
- Adds editable Port, ArtifactRoot and Windows autostart settings with rollback if restart fails.
- Adds Workspace registration/removal with read-only or development presets.
- Adds a Getting Started page explaining Agent, Extension and ChatGPT connection.
- Installer shortcuts now open Control Center instead of a transient maintenance console.
- Setup offers to open Control Center after installation.

## ChatGPT connection
- Extension 3.11.0 supports the official `https://chatgpt.com/` origin while retaining the existing compatibility origin.
- Popup now exposes **Connect this Chat** instead of an ambiguous per-tab enable action.
- Connecting a chat arms the page adapter, opens/resumes a local Bridge session and posts a concise handshake explaining the semantic command path.
- The normal transport remains semantic v2 / fail-closed; retired V3/V4 carrier tests are not restored.

## Extension popup
- Reorganized around the current page: Agent status, ChatGPT connection, Instagram tools and a collapsed Advanced Diagnostics section.
- Test credentials and raw developer controls are removed from the primary UI.
- Activity is refreshed only on demand instead of continuous two-second polling.

## Self Test
- Replaces the stale V3/V4 Self Test with current semantic v2 envelope validation, Native Host ping, Agent round-trip, capability discovery and Bridge bootstrap.

## Activity / observability
- Read-only observability and health actions such as `bridge.activity`, `job.list`, `job.events`, `ping`, capability and status probes no longer create their own command activity records.
- This removes the self-generated Activity Monitor loop while preserving meaningful execution/mutation events.

## Instagram Research Assistant
Uses the same logged-in Instagram browser session. Extension-local capabilities:
- `instagram.profile.scan` — index up to 100 recent posts from a profile into a bounded local corpus.
- `instagram.post.inspect` — inspect a post/Reel and capture caption/visible text, timestamp, hashtags, mentions and media metadata.
- `instagram.scan.get` — page through a stored scan without flooding the chat.
- `instagram.scan.search` — search captions, visible text, hashtags, mentions and Instagram-provided image alt text; every result retains its source post URL.
- `instagram.media.download` — download selected post media to a dedicated browser Downloads subfolder.
- `instagram.media.attach` — attach a bounded batch of selected Instagram media directly to the connected ChatGPT conversation for actual visual review. Media bytes are SHA-256 verified in the attachment path; signed CDN URLs remain local and source attribution uses post URLs only.
- Popup provides direct current-post download and profile indexing; advanced research is driven from the connected ChatGPT conversation.

Visual matching uses a two-stage route: caption/tag/mention/Instagram alt metadata can narrow candidates, then bounded candidate batches are attached with `instagram.media.attach` so ChatGPT can actually inspect the images. Named-person matching must rely on captions/tags/mentions or other explicit source evidence rather than face identification alone.

## Release gates
- Adds a Product UX & Browser Integration source gate covering official ChatGPT origin support, semantic Self Test, clean popup UX, Instagram actions, Activity noise suppression and Control Center packaging.
- Windows installer acceptance launches `Sokna.Bridge.ControlCenter.exe --self-test` after a real silent install.
- Existing Legacy-running-Agent migration, active reinstall, repair, upgrade, rollback, Browser QA, Workspace, Artifact and Component gates remain required.
