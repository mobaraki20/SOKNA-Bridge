# SOKNA Bridge 2.7.1-r11

Status: engineering candidate — not final until integrated qualification and one black-box UAT pass.

## Candidate identity

- Candidate ref: `sokna-agent-2.7.1-r11`
- Agent: `2.7.1`
- Chrome Extension: `3.14.0`
- Semantic transport: `2.1.1`
- Baseline: qualified r10 candidate plus bounded r11 reliability work.

## r11 scope

### Chat delivery reliability
- Resolve multiple ChatGPT file inputs deterministically using composer-local ranking.
- Penalize camera/capture inputs and prefer the general composer upload input.
- Keep ambiguous ties fail-closed.
- Permit a second bounded submit mechanism only when the exact Bridge payload is provably still in the composer.
- Permit body-level ACK only for a full exact SOKNA envelope with the expected unique type/id after the payload has left the composer.

### Bulk browser capture
- New `browser.capture.batch` action.
- Up to 100 capture items in one semantic command.
- Each item may navigate within the already claimed origin, run up to 10 bounded page actions, settle, and capture viewport or full-page evidence.
- Exact-tab claim and same-origin policy remain mandatory.
- Every screenshot remains a content-addressed durable artifact.
- The command returns one bounded `collection_ref`; the full item list is stored in a JSON collection manifest rather than expanded into Chat.

### Artifact collection access
- New `artifact.collection.get` action.
- Bounded pagination over a capture collection manifest, max 20 entries per read.

### Multi-artifact Chat delivery
- New `artifact.out.attach_many` action.
- Up to 100 artifact ids per semantic command.
- Internal Chat submission batches are bounded to 1..10 files.
- Command result stays bounded and reports counts/batch summaries rather than repeating every artifact descriptor.
- Delivery still stops on real user draft, unresolved ambiguity, or unsafe composer state.

## UAT focus

1. Existing r10 bootstrap/doctor/exact-tab/credential login/recovery remains green.
2. Screenshot artifact can attach when current ChatGPT exposes multiple file inputs.
3. RESULT presentation is acknowledged without false positive or duplicate resubmission.
4. A multi-state `browser.capture.batch` returns one collection ref and collection pages can be read.
5. `artifact.out.attach_many` can deliver a small representative collection in one semantic command.
6. Refresh/recovery does not re-execute completed capture commands.

## Release rule

Do not promote r11 if any r10 reliability invariant regresses. Final installer must come from the isolated r11 marker commit and successful Windows lifecycle qualification.
