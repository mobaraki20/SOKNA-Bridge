# SOKNA Bridge 2.7.1-r14 Final / Extension 3.14.2

Final release candidate after October 2026 UAT defect closure.

## Closed in R14

- `plan.stage` accepts safe nested JSON paths below `tools/plans` while continuing to reject absolute paths and traversal.
- Bootstrap separates supported actions from effective actions and applies active-workspace `git`/`gh` policy and availability.
- Browser Capture Map does not report interactive states as reached when no state handler exists or when the required interaction produces no observable state change.
- Catalog category/menu capture actions prefer specific targets before generic edit controls.
- Large canonical capture maps may be supplied through Artifact Plane by validated SHA-256 reference.
- Existing fixes for STATUS/RESULT identity isolation, delivery recovery, terminal retry metadata, `result.get` contract, and send detection remain covered by regression gates.

## Release gate

The final tag and GitHub release are created only after immutable-source verification, JavaScript/Python/Go contracts, final invariants, and the Windows installer build all pass on the exact release commit.
