# SOKNA Bridge 2.7.1-r1

SOKNA Bridge 2.7.1-r1 is a release revision of Agent 2.7.1 with Extension 3.12.1.

## Why this revision exists
Live connected-chat diagnostics showed a false-green state: the semantic observer and Agent probe were healthy, but the Extension had not discovered any assistant-message nodes, so no command could be detected or dispatched while the UI still reported End-to-End Verified.

The original `sokna-agent-2.7.1` tag remains bound to its original commit. This revision uses a new immutable tag instead of moving or overwriting the prior release identity.

## Semantic message intake
- Keeps explicit `data-message-author-role="assistant"` detection as the primary path.
- Adds fail-closed role-evidence fallbacks for supported DOM variants.
- Never executes user or unresolved-role turns.
- Scopes marker extraction to the detected assistant message body.
- Persists semantic scan failures instead of silently swallowing them.
- Adds intake diagnostics including selector mode, role evidence and candidate counts.

## Connection health
- End-to-End Verified now requires verified assistant-message intake in addition to semantic/background/Agent/session/delivery reachability.
- A degraded intake reports **Connected — Message Intake Unverified** instead of false green.
- Diagnostics expose `selector_unverified` when the observer is alive but message intake is not proven.

## Regression coverage
- Runtime fallback test for assistant turns without the legacy author-role attribute.
- Negative test proving user turns are not executable.
- False-green connection-health contract.
- Activation and product contracts aligned with Extension 3.12.1.
- Pull requests targeting the release branch now run the Windows validation workflow before merge.

## Release evidence consistency
- Source-RC metadata now records Agent 2.7.1, Extension 3.12.1 and the exact revision candidate ref.
- Release-version metadata is parameterized instead of carrying stale hard-coded 2.6.0 / 3.10.9 values.
- Published installer/source asset names include the `2.7.1-r1` revision to distinguish them from the original 2.7.1 release.

## Validation
This revision must pass the exact-commit full Windows gate before publication, including:
- semantic/R2 and diagnostic gates,
- Browser QA and component lifecycle acceptance,
- installer build,
- clean install, repair, upgrade, rollback and uninstall acceptance,
- final Windows Agent runtime validation.

The original 2.7.1 release is not modified.
