# SOKNA Bridge 2.6.0

SOKNA Bridge 2.6.0 is the first whole-product release produced from the unified semantic transport line.

Highlights:
- Unified semantic-only command envelope with fail-closed validation and correlated machine-readable NACKs.
- Durable job/activity observability and Extension Activity Monitor.
- Verified bidirectional artifact transfer, including outbound evidence delivery.
- High-level controlled Browser Audit with screenshot/DOM/geometry/accessibility/console/network evidence.
- Persistent work-session bootstrap/resume for new-chat continuity.
- Windows DPAPI-backed local browser credential references.
- Self-contained Windows installer/maintenance lifecycle with repair, upgrade, rollback, automatic rollback, support bundle redaction and uninstall preservation rules.

Release integrity:
- The release is created only after the exact commit passes the full Windows whole-product gate.
- Release assets include the Windows Setup executable, deterministic source bundle, source manifest and exact-RC Windows evidence.
- The evidence file binds the source commit, payload and Setup hashes used by CI.
