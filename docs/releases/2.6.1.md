# SOKNA Bridge 2.6.1

SOKNA Bridge 2.6.1 is an installer/activation reliability release following 2.6.0.

Fixes:
- Detects and safely stops a running legacy SOKNA Bridge V2 Agent before activating the new Agent.
- Requires legacy ownership evidence before stopping a process: canonical legacy PID state, PowerShell process/start-time correlation, and authenticated SOKNA Agent identity probe.
- Removes only legacy SOKNA autostart entries that point at the canonical legacy runtime; legacy config/source files remain preserved for migration evidence and recovery.
- Stops a currently owned SOKNA Agent during Setup reinstall/upgrade even when the payload has already replaced the on-disk runtime hash.
- Probes the configured HTTP endpoint before activation and fails with a specific endpoint-unavailable error instead of surfacing only a generic maintenance start failure.
- Records install preparation evidence in `state/install-preparation.json`.

Windows acceptance additions:
- Starts a real legacy V2 Agent on Windows before Setup.
- Verifies live legacy Agent stop, config/token/port migration, legacy autostart removal, source preservation, and 2.6.1 health.
- Re-runs Setup over an active owned 2.6.1 Agent and verifies ownership-safe stop/restart.
- Retains the existing clean install, repair, upgrade, rollback, failed-upgrade automatic rollback, support-bundle redaction, and uninstall-preservation gates.

Release integrity:
- The release is created only after the exact commit passes the full Windows whole-product gate.
- Release assets include the Windows Setup executable, deterministic source bundle, source manifest, and exact Windows evidence.
